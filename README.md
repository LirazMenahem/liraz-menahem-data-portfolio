# 🏦 Bank Loan Risk & Portfolio Analysis

An end-to-end data analysis project focusing on a comprehensive banking loans dataset, demonstrating database architecture, SQL querying, and risk assessment.

## 🛠️ Tech Stack
- **Database & Querying:** SQL (DDL, Joins, Aggregations, CTEs)
- **Data Cleansing:** Excel
- **Version Control:** Git & GitHub

## 📂 Project Structure
- `data/` - Raw dataset files (Excel/CSV)
- `sql/01_table_design_and_creation.sql` - Database schema and table relationships.
- `sql/02_complex_analytical_queries.sql` - Advanced analytical queries for risk metrics and KPIs.

## 💡 Key Highlights
- **Schema Design:** Built a structured relational database from scratch with proper primary and foreign keys.
- **Risk Assessment:** Analyzed borrower default risks, interest distributions, and DTI (Debt-to-Income) ratios using advanced SQL queries.
- **Portfolio Insights:** Evaluated loan performance segmentation ("Good" vs. "Bad" loans) to drive data-driven financial insights.
